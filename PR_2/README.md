## 1. Общее описание

Проект представляет собой CLI-приложение для анализа и визуализации графа зависимостей пакетов менеджера `npm`. Инструмент извлекает информацию о зависимостях напрямую из npm registry (или тестового файла) без использования штатных средств пакетного менеджера. Программа строит направленный граф зависимостей с помощью алгоритма поиска в глубину (DFS) без рекурсии, разрешает циклические зависимости и вычисляет порядок загрузки пакетов (на основе топологической сортировки). Результат транслируется в язык декларативных диаграмм D2 и визуализируется в формате SVG.

## 2. Описание всех функций и настроек

Анализатор поддерживает запуск со следующими параметрами командной строки:
- `--package` — имя анализируемого пакета.
- `--url` — URL-адрес репозитория (например, `https://registry.npmjs.org`) или путь к локальному файлу тестового графа.
- `--pkg-version` — версия целевого пакета.
- `--output` — путь и имя итогового файла для сохранения изображения графа (в формате `.svg`).
- `--max-depth` — максимальная глубина транзитивного анализа зависимостей (целое неотрицательное число).
- `--test-mode` — флаг для включения режима тестирования (чтение графа из локального JSON-файла вместо выполнения сетевых запросов).

**Основные выполняемые операции:**
- Парсинг конфигурации и валидация аргументов.
- Извлечение зависимостей с очисткой версий от спецсимволов.
- Вывод на экран порядка загрузки зависимостей (от независимых пакетов-листьев к корневому узлу).
- Генерация файла `graph.d2` и автоматический рендер графического SVG-изображения.

## 3. Описание команд для сборки проекта и запуска тестов

Для полноценной работы визуализации (Генерации SVG) требуется установленная в системе утилита командной строки [D2](https://d2lang.com/).

Проект включает готовые скрипты с тестовыми примерами запуска (для тестового графа с циклами и реальных npm-пакетов).

Запуск тестов на Linux/macOS:
```bash
chmod +x run.sh
./run.sh
```

Запуск тестов на Windows:
```bash
.\run.bat
```

Пример самостоятельного ручного запуска для реального пакета (express):
```bash
python stage5.py --package express --url [https://registry.npmjs.org](https://registry.npmjs.org) --pkg-version 4.18.2 --output express_graph.svg --max-depth 2
```

Пример самостоятельного ручного запуска для тестового репозитория (test_repo.json):
```bash
python stage5.py --package A --url test_repo.json --test-mode --pkg-version 1.0.0 --output test_graph.svg --max-depth 5
```
