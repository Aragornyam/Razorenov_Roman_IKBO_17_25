## 1. Общее описание
Проект представляет собой эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI). Заголовок окна формируется динамически на основе данных операционной системы. Эмулятор работает с виртуальной файловой системой (VFS), загружаемой из CSV-файла, где бинарные данные предполагают кодирование в формате base64. Все операции производятся исключительно в оперативной памяти.

## 2. Описание всех функций и настроек
Эмулятор поддерживает запуск со следующими параметрами командной строки:
* `--vfs` — путь к физическому расположению CSV-файла виртуальной файловой системы.
* `--script` — путь к стартовому скрипту, содержащему набор команд. Выполнение скрипта прерывается при первой же ошибке.

**Поддерживаемые команды:**
* `ls` — вывод содержимого директории (заглушка).
* `cd` — смена директории (заглушка).
* `exit` — завершение работы эмулятора.
* `vfs-info` — служебная команда, выводящая имя VFS и хеш SHA-256 ее данных.
